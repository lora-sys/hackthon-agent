EMERGENCE

AI Agent 协作生存模拟器（Hackathon 演示页）

本页用于快速展示核心能力：LLM 规划、工具执行、世界状态联动与证据链可视化。

GitHub 仓库 README 提交说明

项目定位

  • 不是聊天 UI，而是 Agent 回路：Plan → Execute → Feedback。
  • 关键状态推进要求 source=model，防止“纯假数据推进”。
  • 降级时保留可见执行流，避免长时间“黑箱等待”。

评审看点

  • 实时争论与投票理由、执行动作、资源/风险变化同屏联动。
  • Planner 单飞去重 + 缓存 + 自适应超时，避免请求风暴。
  • 可替换环境执行层（本地适配器 / 外部引擎）。
